# Markdown 实时编辑与专有语法控件

工作台通过 `md-slide-studio edit deck.md` 启动。编辑器以 Markdown 原文作为文档状态，实时和源码模式共用光标、选区与撤销历史。

顶栏「文件」菜单包含「打开 Markdown」和「打开工作文件夹」。可以一次选择多个 Markdown，每份文件和每个工作文件夹各占一个标签。CLI 启动稿件位于第一个标签。

在文件夹标签中，用标签栏右侧的下拉列表切换 Markdown。图片路径以当前 Markdown 所在目录为起点。切换标签或稿件时保留未保存的修改，标签上的圆点表示有待保存的草稿，关闭标签时会提示确认。

「文件 → 最近 Markdown」列出最近打开的独立文件和项目内稿件。「文件 → 最近项目」会回到项目上次使用的稿件。历史记录保存在当前站点的浏览器存储中。浏览器保留文件访问权限时可以直接重开，其他情况下按浏览器提示授权或重新选择文件、文件夹。

## 编辑模式

- **实时**会排版标题、强调、列表、链接和代码，并在编辑区预览 Markdown 图片。光标或选区进入相应行时，该行显示原始标记。
- 行内公式支持 `$…$` 和 `\(…\)`，独立公式支持 `$$…$$` 和 `\[…\]`。点击公式或把光标移入公式时可编辑 LaTeX，移开后恢复排版。
- 标记为 `mermaid`、`pele` 或 `diagram` 的反引号代码块会由 Pele 渲染。点击编辑区的图表即可回到原始代码。绘图语法错误时显示原始代码。
- **源码**显示原始 Markdown 和行号。可以随时切回实时模式。
- 文档开头的 YAML 配置折叠为「文档配置」，可展开编辑。普通单行 Markdown 注释也可以从控件打开源码。

## 页面设置

```markdown
<!-- slide: layout=two-col | section=实验设计 | transition=fade -->
```

实时模式在指令所在行提供版式下拉、章节名称和转场下拉。选中「自动」将移除 `layout`，由渲染器按正文内容推断版式。编辑区底部也能设置当前页的版式，适用于源码模式和还没有指令的页面。

转场选项遵循渲染器支持的 `fade`、`slide`、`none`。章节名称可用单个词或连续的中文名称。控件保存对应的 Markdown 属性，同行的其他属性保留。

## 容器

```markdown
::: notes
这是演讲者备注。
:::

::: box 核心结论
这是重点卡片。
:::

::: fragment step=1 effect=fade-up
这是第一步显示的内容。
:::
```

- 「插入块」可以添加讲稿、重点卡片和分步动画。
- 可以展开或折叠完整的容器。在实时模式点开「编辑源码」后，也可直接改 `:::` 标记。
- 讲稿正文直接在编辑器修改，重点卡片的标题可以从块头编辑。
- 分步动画在块头配置正整数步骤和受支持的 `fade`、`fade-up`、`none`。同一步骤的多个片段同时出现。
- 可折叠容器可以相互嵌套，代码围栏中的示例标记保留为代码。

## 大纲与成片

桌面上可以拖动两条分隔线，或聚焦分隔线后按左右方向键调整宽度。窄屏下用上方按钮切换大纲、编辑与成片预览。

点击大纲中的页面会同时定位编辑区和成片。点击预览空白处后可按左右键切换当前页，分步模式下可逐步播放。预览翻页保留 Markdown 选区，点击成片内容可以主动定位到 Markdown。顶栏「演示」从当前页打开独立播放器。「导出 HTML」将当前编辑内容下载为一个 HTML 文件，内嵌可读取的本地图片与图表、播放器和公式渲染所需的资源。远程图片仍使用原有网址。

同一浏览器重新打开同一份演示稿会恢复当前预览页、Markdown 选区、编辑模式、分步状态和大纲折叠状态。工作台也会记住栏宽。浏览器选择的本地工作文件夹需要重新打开以获取文件访问权限，演示稿正文按各模式的保存方式写入本地文件或服务端。

CLI 启动稿件会自动保存到 Markdown 文件，也可通过「保存」或 `Ctrl+S`（macOS 为 `⌘S`）立即提交。通过浏览器打开的稿件可以用「导出 .md」下载，有写入权限的工作文件夹也可以用「保存到本地」写回源文件。原文暂时包含不可渲染的语法时，成片区显示渲染错误，编辑器仍可继续修改。
