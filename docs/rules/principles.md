# 核心开发硬约束清单 (Principles & Invariants)

## 架构与归属约束
- **C1 (工具独立性)**：`jc-slide-studio` 必须能在脱离 `jc-slides` 或其他 Agent Skill 目录的环境下独立安装与运行，严禁在运行时硬编码回退到任何本地 skill 目录。
- **C2 (权威源唯一性)**：Markdown 文件是唯一持久权威真实源。HTML、DOM 和内存 AST 均为派生物，可随时丢弃重建。
- **C3 (禁止全量逆向转换)**：可视化回写绝不能将整个 DOM 逆向转换为 Markdown，必须通过精确的源码位置区间（Source Range）进行局部字符串替换。
- **C4 (离线可用性)**：正式导出的 HTML 成片必须自包含或基于可相对引用的静态资源，严禁依赖联网 CDN 或本地开发服务器。
- **C5 (输出命名严禁 index.html)**：单文件成片默认从输入源文件名或目录名推导，严禁使用通用的 `index.html`，防止多汇报覆盖与索引混乱。

## 保存与并发约束
- **C6 (原子写入)**：写盘操作必须通过临时文件加原子重命名完成，写盘失败时内存编辑缓冲区不得丢失。
- **C7 (外部变更安全)**：检测到外部进程修改源文件时，必须主动提示冲突，严禁静默覆盖。
- **C8 (单写者会话)**：首版默认单一写入会话，其余连接为只读，避免无协调的多人并发冲突。
