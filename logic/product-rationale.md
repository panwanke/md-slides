# 产品定位与价值主张 (Product Rationale)

## 1. 业务痛点 (WHY)
此前，学术汇报幻灯片（jc-slides）的解析、渲染与播放器资源高度依附于特定 Agent 技能目录中：
- **耦合严重**：必须在包含特定 skill 的环境中运行，无法作为纯粹的代码工具独立安装或复用。
- **编辑体验割裂**：修改幻灯片完全依赖手动修改 Markdown 文本或由 Agent 盲改，缺乏实时可见的所见即所得交互。
- **定位成本高**：长达数十页的汇报稿，在浏览器中看到排版问题，需要手工在数百行 Markdown 中查找定位。
- **回写风险大**：如果采用传统所见即所得编辑器直接将 DOM 转回 Markdown，会导致公式、特殊注释、排版格式全面劣化。

## 2. 价值主张 (Value Proposition)
`jc-slide-studio` 提出并实现了：
1. **独立工具化**：作为独立的 Python 包（内置静态 React 工作台），支持 CLI 和桌面/浏览器访问。
2. **保真双向定位**：基于精确源码区间映射（Source Range），点击预览 DOM 节点即可定位源码行号与选区。
3. **受控回写事务**：通过 AST 局部替换机制，仅更新修改的文字或属性，不触碰周围注释、LaTeX 公式与排版结构。
4. **统一撤销历史**：界面修改与源码编辑进入同一个撤销栈，支持无缝 undo/redo。
