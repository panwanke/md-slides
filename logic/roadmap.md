# 宏观路线图与里程碑 (Roadmap)

## 里程碑规划 (Milestones)

| 里程碑 | 独立交付物 | 核心目标与完成条件 | 依赖关系 |
|---|---|---|---|
| **M0：契约与仓库设计** | 治理体系、架构设计、协议契约、测试样例、基础工程骨架 | 目录规范化、ARA 治理合规、工程可构建、契约冻结 | - |
| **M1：独立核心引擎** | 解析/渲染/CLI (`doctor`, `check`, `render`, `preview`) | 完全脱离 skill 目录独立运行，旧稿对照无回归 | M0 |
| **M2：编辑工作台** | FastAPI 服务、React + CodeMirror 6 工作台、页级双向定位 | 实时防抖构建、光标聚焦切页、未保存内容恢复 | M1 |
| **M3：可视化编辑与回写** | 元素级源码映射、受控回写事务、统一撤销栈 | 界面修改标题/段落/notes/版式，仅替换局部源码 | M2 |
| **M4：工具发布包** | 单进程可执行包、静态前端内嵌 (`web_dist`)、端到端测试 | 用户单命令启动，无须 Node 开发环境 | M3 |
| **M5：Skill 接入** | 精简版 `jc-slides` skill、Ops 迁移、薄适配器 | skill 成功委托 Studio 完成原有工作流 | M4 |
| **M6：实际汇报验收** | 真实博士/学术汇报测试与全流程接入验收 | 导航、动画、图件、离线成片交付无关键回归 | M5 |

## 阶段门禁 (Gate Invariants)
- **Gate 1 (M0 → M1)**: ARA check 全绿，`pyproject.toml` 与模块结构就绪。
- **Gate 2 (M1 → M2)**: 旧稿件渲染 HTML 逐字节对比无破坏性差异。
- **Gate 3 (M3 → M4)**: 回写往返（Round-trip）测试在 Windows CRLF、中文、Emoji、嵌套列表下 100% 保持未修改区域不变。
- **Gate 4 (M4 → M5)**: 纯净环境验证无额外依赖单命令运行。
